Première expérience : clique « Lancer le séquenceur ». Tu entendras déjà huit pas. Aucun branchement supplémentaire n'est nécessaire.

03 / Sauvegarder et recommencer

Le rack est une expérience indépendante : aucun logiciel à installer, aucune bibliothèque à télécharger, aucun serveur nécessaire.

Le son nécessite Chrome, Edge ou Firefox avec une action utilisateur (bouton Lecture). Ouvrir ce fichier HTML suffit ; le publier sur GitHub Pages rendra aussi le laboratoire accessible par URL.
